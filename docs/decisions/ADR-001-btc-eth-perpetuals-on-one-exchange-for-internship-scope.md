# ADR-001: BTC/ETH perpetuals on one exchange for internship scope

Status: Accepted
Date: 2026-08-08 (Master Blueprint v2.0)

## Decision
BTC/ETH perpetuals on one exchange for internship scope.

## Rationale
Narrow market is an engineering advantage: one symbol model, one fee/funding model, one order API, one data vocabulary, one replay environment.

## Consequences
Expansion to other venues or traditional futures only after the research-to-paper loop is trustworthy.
