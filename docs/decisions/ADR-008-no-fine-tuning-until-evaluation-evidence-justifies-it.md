# ADR-008: No fine-tuning until evaluation evidence justifies it

Status: Accepted
Date: 2026-08-08 (Master Blueprint v2.0)

## Decision
No fine-tuning until evaluation evidence justifies it.

## Rationale
Most agent quality comes from instructions, tools, schemas, evaluation and model selection. Fine-tuning before that is premature and costly.

## Consequences
Fine-tuning considered only after a high-quality dataset exists and prompting/tools/evals have demonstrably plateaued.
