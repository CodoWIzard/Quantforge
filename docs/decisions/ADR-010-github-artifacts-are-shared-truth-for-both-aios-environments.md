# ADR-010: GitHub artifacts are shared truth for both AIOS environments

Status: Accepted
Date: 2026-08-08 (Master Blueprint v2.0)

## Decision
GitHub artifacts are shared truth for both AIOS environments.

## Rationale
Two independent AIOS environments diverge unless reality is defined by versioned artifacts rather than chat memory.

## Consequences
No important decision exists only in a Discord thread. Issues, PRs, ADRs and context files govern.
